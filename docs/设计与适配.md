# 设计与适配

公开版保留来自原工程的 tvOS 主屏构图、玻璃控制中心、应用卡面和遥控焦点；设备入口、签名与分发环境改为独立配置。布局使用 1920×1080 设计坐标，并依据实际渲染尺寸缩放；字重、圆角和焦点由 TvAppearance 及 HomeActivity 的 Control/Panel 统一管理。

## 主要结构

六列横卡、首排悬浮 Dock、Top Shelf 标题区、展开栅格和右上控制中心。应用名称由唯一覆盖层定位到选中卡片，避免 Tile/父层重复文字。选中动画与移动/展开共享状态，焦点外扩需留出裁剪空间。

齿轮焦点圆边缘与控制中心开场圆角采用局部绘制修复，沿用现有动画、字形、文字和背景风格。`Glass.clipContent` 统一控制 outline、children 和 padding 裁剪：非滚动 Glass 关闭三项，时间 LinearLayout 也关闭子视图和 padding 裁剪；带滚动内容的面板保留默认裁剪。

控制中心模块的焦点 Fill 由 Glass 在材质之后、内容之前绘制，每次绘制先使用实际宽高设置 bounds，从第一帧保持正确圆角且不盖住字形或文字。Glass 管理 Fill 的 Drawable callback／verifyDrawable；模块以同一个局部 radius 创建玻璃与 Fill，Control 只绑定一个宿主，已移除独立 fillLayer 和双宿主路径。

卡面优先接受实际宽幅 banner；正方形 banner 不能直接裁切为横幅。自适应图标前景和普通图标按实际可见边界归一，背景依据原图类型生成。AppArtwork 保留这些处理，没有附带其他应用的 logo 素材。

重图片处理/模糊在后台完成，主线程负责布局与属性动画；旧 API 和系统关闭动画的路径需要按实际设备验证。公开整理仅新增原生“关于与恢复”内容，复用现有 Panel、字阶和按钮。

## 背景选择与浏览

背景来源复用现有 Panel 和选中勾，改为多选：点击立即勾选／取消并保存，面板保持打开，至少保留一个来源；旧单选设置成为初始选中项。用户选择的 `sources` 集合与当前活动 `source` 分开，焦点不等于勾选状态；编辑并保存自定义地址会保留其他选择。

Home重新获得窗口焦点或最后一个面板关闭后，复用 `focusInitial` 恢复当前背景浏览／应用焦点，用于修复返回时触摸模式恢复占用首个方向键的问题；已在隔离 API35、1920×1080 的真实按键流程中验证关闭来源面板后的首个 RIGHT 换图、LEFT 返回；不代替电视物理遥控验证。

主屏可见期间按30分钟节奏、或手动“更新背景”时，在已选来源中轮换；只有一个图库来源时继续轮换其图片。图库范围统一为艺术、NASA、摄影集；全屏左右只在当前已选图库内前后浏览，当前活动项不是图库时可启用一个已选图库，没有选中图库则保持当前背景，均不改变勾选集合。上键浏览、下／返回恢复应用以及原有无障碍说明继续保留。

来源失败时可复用自身有效缓存，没有可用缓存时只尝试其他已选项；所有已选项及可用缓存都不可用时才显示离线海岸。未选“每日风景”时不会因为最近观看或自定义失败而联网请求每日图片。

“摄影集”的 kind 为 `photography`，目录条目使用 `source=personal`、`license=USER-PROVIDED`；资产与目录只写入各自工程的 `assets/photography/`，该目录被公开 Git 忽略。照片标题使用用户指定的显示名，未指定时沿用文件名（去扩展名），系列署名只显示“摄影集”；作者／日期为空并隐藏，不标作 CC0。电视从包内离线读取；公开工程只提供代码和导入脚本，默认未配置摄影集，选中空摄影集时沿既有边界尝试其他已选来源／离线海岸。

在自己的项目根目录运行 `python3 tools/import_photography.py '用户本机照片文件夹'`，可选 `--titles <JSON>` 指定显示名：键为源目录相对文件名，值为显示名；省略或未映射的照片沿用去扩展名的文件名。需要已有 ffmpeg／ffprobe，不自动安装。支持1–64张 JPEG／PNG／WebP／BMP／TIFF，按比例适配2560×1440并以q2导出JPEG，移除导出副本的源元数据，原文件不改；目录64KiB、每图8MiB的有界校验继续生效。具体目录字段见[艺术背景设计](艺术背景设计.md)。这些变化不扩展视觉系统，也不改变 HOME、签名和更新授权。

## 小米需要补的事实

1. 实际 API、ABI、渲染分辨率、密度、遥控器键值。
2. 标准 HOME 角色/选择器是否可用；厂商是否截获物理 Home；重启与覆盖更新后是否保持。
3. 系统设置入口与切换前记录的原 HOME 是否可启动。
4. 如需观看记录，确认小米实际导出的 provider/服务、权限与字段，再增加独立适配。
5. 图标素材质量、长标题、字体放大以及真实 GPU 动画表现。

没有某个 provider 时遵守已选来源与离线海岸的回退边界，不能把 TCL URI 替换一个厂商名称就认为已适配。网络数据、诊断和模拟器假数据应分开。

视觉参考为 Apple TV **系统主屏**，并非 Apple TV 视频应用；参考资料见交接指南的官方链接，仓库不再分发官方截图。
