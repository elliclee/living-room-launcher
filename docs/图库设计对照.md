# 图库与背景多选：既有设计系统扩展对照

结论：艺术、NASA、摄影集及背景多选属于现有主屏的普通扩展，署名沿用既有局部排版。图片继续由既有 Wallpaper 绘制，来源选择复用 Panel、白色焦点和选中勾；没有建立新的全局视觉系统。摄影集代码与导入格式已落地，本说明记录选择、轮换、署名和离线边界，构建／测试结果由独立验证记录拥有。

## 实际浏览交互

1. 应用首排按 **上** 进入背景浏览；应用栅格与 Dock 下移退出，应用名称及 Top Shelf 操作不再接收背景浏览焦点。右上时钟／控制中心入口继续可见。
2. 浏览时按 **左／右**，在当前已选图库中切换前／后图片，图库统一包括艺术／NASA／摄影集；活动来源不是图库时可启用一个已选图库。没有选中图库时保持当前背景，左右操作始终不增删或替换勾选集合。
3. 加载过程中独立方向按键按净位移合并，累计范围为 -8 到 8；按住产生的重复事件不逐次排队请求。
4. 按 **下** 或 **返回** 退出浏览，隐藏角落说明并恢复既有选中应用位置。现有按键记录中恢复的应用为 YouTube。
5. 浏览时再按 **上**，焦点移到右上控制中心入口，随后确认打开；不是按上直接替用户执行设置动作。

这些遥控行为与背景焦点目标的无障碍说明继续有效；全屏没有可见按键提示。每30分钟及手动“更新背景”轮换已选来源，单图库继续切换图片；来源失败可保留自身有效缓存，需要切源时只尝试其他已选项，全部不可用才显示离线海岸。最近观看／自定义失败不会联网请求未选的每日风景。作品标题和署名位于来源说明／浏览角落，图库元数据不创建视频包入口；不会把艺术或摄影内容描述成可精确续播的视频。HOME、签名与更新协议保持既有语义。

摄影集在自己的项目根目录通过 `python3 tools/import_photography.py '用户本机照片文件夹'` 导入；可选 `--titles <JSON>`，键为源目录相对文件名、值为显示名，省略或未映射时沿用去扩展名的文件名，具体私人命名不进入公开数据。需要已有ffmpeg／ffprobe，不自动安装。输入为1–64张JPEG／PNG／WebP／BMP／TIFF，输出按比例适配2560×1440、q2 JPEG，移除导出副本的源元数据，原文件不改；目录64KiB／每图8MiB的有界规则继续适用。目录字段详见[艺术背景设计](艺术背景设计.md)。

## 证据边界

`keys-result.json` 声明的环境是隔离 API35 Google APIs **手机系统镜像**、1920×1080。既有记录通过了：上键进入无应用焦点的全屏背景、右键改变艺术作品身份、左键返回前一作品、下键恢复原应用名称／焦点，以及应用行内右键不改变壁纸。本轮读取并记录这些结果，没有重跑按键脚本；该记录没有声称完整 NASA 前后切换链也已通过。

静态截图可证明对应时刻的构图、署名与焦点外观，不能单独证明动画手感、网络长期可用、连续按键时延或性能。API35 镜像结果不能替代 TCL、小米或其他具体电视的物理遥控、HOME角色、重启保持及公开版安装结果。

本轮实际发现来源面板返回后首次方向键被触摸模式恢复占用；当前实现已在Home重获窗口焦点／最后面板关闭后复用 `focusInitial` 恢复当前背景或应用焦点，已在隔离 API35、1920×1080 的真实按键流程中验证关闭来源面板后的首个 RIGHT 换图、LEFT 返回；不代替电视物理遥控验证。

此次仅同步多选、轮换与已落地摄影集格式，保留既有局部署名；未改变全局tokens或补写sidecar。文档工作未运行构建、设备、联网、安装、性能或全量测试，不代写摄影集验证结论，也不替代独立验证记录和finish verdict。
