# 公开版与原工程差异

从本地 5.2.2 开发快照提取八个首页/卡面/背景/更新类，使用独立包名 io.github.elliclee.livingroom 与公开版从 1.0.0/code1 起始（本次图库更新为 1.1.0/code2）。原工程不变。

不纳入诊断上传、原 APK 提取、TCL 安装策略修改、历史构建、设备报告或原签名。设置和原首页导航改为按本机公开系统入口与已解析 HOME 选择。保留 TCL 只读观看记录适配并注明小米待适配。

构建改为检测本机 SDK/JDK，首次生成独立签名与更新授权；后续校验该项目自己的签名身份，不依赖原工程的历史 APK。公开源码按明确文件清单提交；生成物和本机配置忽略。

已完成独立构建、HOME/签名检查、5 个更新服务/真实 APK 发布测试及干净源码导出构建。公开版没有新设备运行验证，只发布源码，不发布带本机更新授权的 APK。
