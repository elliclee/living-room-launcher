## 未覆盖

本次公开整理没有安装到用户的电视，也没有运行新的模拟器 UI 验证。公开版设置导航和“关于与恢复”尚待设备交互验证。小米电视型号/系统未知，因此物理 Home、重启保持、观看记录、来源授权、GPU 性能等均未验证。Android7/API24 是 Manifest 声明的最低版本，不代表所有旧机型已通过。

原私人项目曾进行 TCL 实机默认 HOME 和隔离模拟器 UI/更新验证；这些结果不能直接当作独立公开副本或小米适配的通过记录。朋友应按交接指南取得自己的证据。
