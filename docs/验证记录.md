# 公开参考版验证记录

公开版为独立包名 `io.github.elliclee.livingroom`；初始 1.0.0/code1，当前图库版为 1.1.0/code2。源自私人工程 5.2.2 的代码快照，版本号不是原用户已安装版本证明。

## 本地已完成

- 现有 JDK17、SDK35/build-tools35.0.0 构建通过。
- APK 签名、zip alignment、唯一 HOME/Leanback 入口、预期权限与 DEX 对应检查通过。
- 使用本副本新生成签名及更新授权，未读取或使用私人签名/历史 APK。
- 更新 HTTP 与真实 APK 发布共 5 个测试通过（无跳过），覆盖错误签名/包名/缺少 HOME 的真实 APK、失败发布保持旧清单，以及鉴权、路径、配置和摘要绑定。
- 从 Git 索引导出的干净源码目录独立初始化、生成另一份新签名并构建通过，证实不依赖源工程或已有 .build；临时目录已清理。

## 未覆盖

初始公开整理没有运行模拟器；本次图库模块已补充隔离模拟器测试，详见下节。仍没有安装到用户的电视。公开版设置导航和“关于与恢复”尚待设备交互验证。小米电视型号/系统未知，因此物理 Home、重启保持、观看记录、来源授权、GPU 性能等均未验证。Android7/API24 是 Manifest 声明的最低版本，不代表所有旧机型已通过。

原私人项目曾进行 TCL 实机默认 HOME 和隔离模拟器 UI/更新验证；这些结果不能直接当作独立公开副本或小米适配的通过记录。朋友应按交接指南取得自己的证据。

## 1.1.0 艺术/NASA 与遥控浏览

- 构建成功，原公开版签名与 HOME/权限检查通过；素材共17条，10张内置图片已核对摘要和真实 JPEG 解码。
- `python3 -W error::ResourceWarning -m unittest discover -s tests -v`：7 个测试通过，包含图库目录/素材一致性及既有5个更新服务/真实 APK 发布测试。
- `python3 tools/test_android_gallery.py --serial emulator-5582`：在已存在的任务专用 API35 Google APIs 手机镜像上，公开 APK 的3组 instrumentation通过：目录/10张解码/前后循环、许可来源与路径拒绝、真实加载/缓存/前后图片及NASA署名区分。工具只允许明确选择的模拟器，修改其应用背景缓存与偏好，不操作实机。
- 私人同功能版本另以外部真实按键验证 UP 浏览无应用焦点、RIGHT 图片ID变化、LEFT 返回、DOWN 恢复原应用名称/焦点、应用模式RIGHT不改背景；同镜像从NASA资产服务联网取得未内置图片 S39-23-020。两套包名的背景模块和交互差异已逐段同步；公开版原设置/恢复导航不由私人按键结果证明。
