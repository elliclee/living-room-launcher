# 公开参考版验证记录

公开版为独立包名 `io.github.elliclee.livingroom`；初始 1.0.0/code1，当前为 1.2.1/code6（图库功能始于 1.1.0/code2）。源自私人工程 5.2.2 的代码快照，版本号不是原用户已安装版本证明。

## 本地已完成

- 现有 JDK17、SDK35/build-tools35.0.0 构建通过。
- APK 签名、zip alignment、唯一 HOME/Leanback 入口、预期权限与 DEX 对应检查通过。
- 使用本副本新生成签名及更新授权，未读取或使用私人签名/历史 APK。
- 更新 HTTP 与真实 APK 发布共 5 个测试通过（无跳过），覆盖错误签名/包名/缺少 HOME 的真实 APK、失败发布保持旧清单，以及鉴权、路径、配置和摘要绑定。
- 从 Git 索引导出的干净源码目录独立初始化、生成另一份新签名并构建通过，证实不依赖源工程或已有 .build；临时目录已清理。

## 未覆盖

初始公开整理没有运行模拟器；本次图库模块已补充隔离模拟器测试，详见下节。仍没有安装到用户的电视。公开版设置导航和“关于与恢复”尚待设备交互验证。小米电视型号/系统未知，因此物理 Home、重启保持、观看记录、来源授权、GPU 性能等均未验证。Android7/API24 是 Manifest 声明的最低版本，不代表所有旧机型已通过。

原私人项目曾进行 TCL 实机默认 HOME 和隔离模拟器 UI/更新验证；这些结果不能直接当作独立公开副本或小米适配的通过记录。朋友应按交接指南取得自己的证据。

## 1.2.1 控制中心开场初始焦点

- 用户确认私人5.4在TCL真机上“电视设置”整块按钮的边角仍在展开时变化；此前圆角Canvas测试及模拟器静态截图没有覆盖这一真机现象。新回归在旧公开1.2.0上确认首个模块在窗口显示准备阶段选中效果未完成。
- 首次获焦预置解决了开场时序缺口，但慢放录像仍复现左侧切角，独立审查给出fix。进一步用实际窗口PixelCopy复现半透明合成层对焦点外扩的裁切，软件Canvas不会覆盖此路径。最终由带56设计px留白的frame承接控制中心进入/退出alpha，surface仅位移，原有首选中预置及后续焦点过渡保留；其他面板保持原alpha宿主。
- 公开1.2.1/code6与私人5.4.1/code20分别构建、签名、对齐和HOME校验通过。两包运行同一控制中心测试源码的3组原生检查均通过：已有圆角/裁剪边界、真实菜单在可绘制前已选中及连续3次绘制保持最终白底/圆角/比例，PixelCopy实际窗口在半透明期间保住开场模块左缘及右胶囊选中、最大退出位移时的右缘，后续焦点移动继续动画。测试运行于指定的API35 Google APIs手机镜像，不是TCL硬件。
- 没有重新运行未改动的图库/来源及更新服务全量测试。新版本消除TCL边角变化的实际效果尚需真机确认；上述回归证明已观测的焦点时序、模拟器GPU合成裁剪及相应代码路径。

- 私人最终包5倍慢放展开九格均保留圆弧；右胶囊选中退出四格未见边缘被切，关闭重开/方向键/字号1.3/动画关闭流程通过。PixelCopy使用冻结alpha=.5及最大退出位移的稳定夹具；不是对动画逐帧曲率的量化。原生测试中被测包作为非默认HOME任务运行，随后恢复模拟器原默认HOME；不据此宣称电视默认HOME行为通过。
