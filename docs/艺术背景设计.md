# 西方艺术背景

增加 art 来源，保留用户原背景选择。选用芝加哥艺术博物馆 API 标明 is_public_domain=true 的 12 幅横向经典绘画，原始字段/作品页/IIIF 图片地址/CC0 与核对日期写入目录；8 幅内置最大 2560×1440 JPEG，在线按 IIIF 获取有界图片。每幅图与元数据绑定，原画不做生成或改绘。

艺术画廊是背景多选集合中的一个来源；主屏可见时每30分钟和手动“更新背景”在已选来源间轮换，仅选一个图库时继续切换其图片，离开主屏不启动后台服务。内置图片即时读取，其余图片按官方地址联网获取；艺术图片获取失败可使用内置下一幅，缓存只保留当前艺术背景。标题/作者/年份/来源显示在背景来源说明与全屏浏览角落，不占据观看记录的 Top Shelf。

图片沿用 8MiB 下载、解码尺寸和原子缓存上限；清单不超过 64KiB/64 幅，拒绝非公共领域/未知许可/非法图片或本地资源路径。下一幅跳过当前项，不改变 HOME/签名/更新协议。公开版与现有私人版使用同一份艺术模块和素材。

验证围绕目录来源/摘要与许可、真实图片解码、下一幅/定时缓存/离线轮换、艺术缓存损坏、原背景选项回归。图库首版构建分别为公开版 1.1.0/code2、私人版 5.3/code16；私人更新源完成验证后发布，公开仓库同步源码和素材。

官方依据：https://api.artic.edu/docs/ 。接口说明提醒 IIIF 也可能返回非公共领域图片，因此素材目录必须逐件核对 is_public_domain，而不是只凭可访问的图片 URL。

## NASA 与遥控浏览（用户追加）

新增 NASA 太空来源：5 张经核对的 NASA/JSC 航天摄影，其中 2 张内置。通过官方 Image and Video Library API 获取元数据及有界图像地址；按 NASA 图片与媒体使用规范保留署名，不将 NASA 全部图库标为 CC0。目录保存每张图片的来源、日期与核对记录。

从首排按上进入背景浏览：应用栅格与 Dock 退出，左右切到当前已选图库的前后图片，下或返回恢复原应用焦点，上可进入控制中心。图库统一包括艺术、NASA和摄影集；当前活动来源不是图库时，左右浏览可启用一个已选图库，没有选中图库则保留当前背景，不会自动勾选艺术画廊或覆盖选择集合。连续按键在一次加载过程中按位移合并，最多累计八步，防止串行请求堆积；不伪造观看记录。

NASA 来源：https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf ；使用规范：https://www.nasa.gov/nasa-brand-center/images-and-media/ 。没有调用需要 API Key 的 APOD，不使用共享 DEMO_KEY。

## 多选来源与离线摄影集

“背景来源”使用既有 Panel、白色焦点和独立选中勾；点击即保存勾选／取消状态并保持面板，至少保留一项。旧 `source` 单选设置保留为初始选中项；新的 `sources` 集合表达用户选择，活动 `source` 只表达当前轮换位置。保存自定义地址会加入／保留自定义项，同时保留其他已选项。

轮换与失败回退都尊重该集合：有效缓存可继续显示，需要切源时只尝试其他已选来源；所有已选项均不可用后才用内置海岸。未选每日风景时，最近观看／自定义失败不会触发每日图片联网。

“摄影集”是同一套图库交互中的离线来源，兼容多选、来源轮换与左右前后浏览。`sources` 集合及活动 `source` 使用图库 kind `photography`；其目录条目的 `source` 为 `personal`、`license` 为 `USER-PROVIDED`。照片导入后随各自 APK 打包，电视运行时不依赖电脑目录或网络；公开工程只提供代码和导入脚本，不包含私人照片，`assets/photography/` 中的目录及图片均被公开 Git 忽略。

在各自项目根目录执行：

```sh
python3 tools/import_photography.py '用户本机照片文件夹'
```

可选 `--titles <JSON>` 接收“源目录相对文件名 → 显示名”的JSON对象；省略该选项或未映射的照片沿用去扩展名的文件名。私人照片的具体命名映射不进入公开数据。

脚本需要已有 ffmpeg／ffprobe，不自动安装工具；递归读取1–64张 JPEG、PNG、WebP、BMP或TIFF，按原始内容摘要去重。每张图按比例适配2560×1440，以 ffmpeg `-q:v 2` 导出JPEG并移除导出副本的源元数据；原文件保持不变。最终资产输出到本工程 `assets/photography/`，目录不超过64KiB、每图不超过8MiB；只替换本工具管理的已有摄影集，并保留本次替换备份。

生产目录为 `assets/photography/catalog.json`，使用 `format_version=1` 和 `managed_by=living-room-photography-import`。条目 `id` 为原文件SHA-256，图片放在 `photography/<id>.jpg`，`image_url` 为对应的 `asset://photography/<id>.jpg`；`sha256`／`bytes` 校验导出图片。`display_title` 取用户映射的显示名，未指定时取去扩展名的文件名，`display_artist`／`date` 留空；不猜测作者、日期或CC0授权。

公开工程默认没有私人照片，缺失或空摄影集是已知未配置状态；选中时可使用其他已选来源，全部不可用才显示离线海岸，不从未选来源补图。自动30分钟与手动“更新背景”轮换已选provider，左右仅浏览当前已选图库内的图片，不改勾选集合。

## 全屏署名的局部排版

全屏浏览不显示“左右切换图片／下键返回应用”等可见按键提示；方向键、返回键和背景焦点目标的无障碍操作说明继续保留。署名分为三个独立角色：

| 角色 | 设计字号／字重 | 颜色 |
| --- | --- | --- |
| 作品／摄影标题 | HEADLINE 38／500 | 既有 TEXT 近白 |
| 作者或机构、日期 | CAPTION2 23／400 | Android ARGB `0xE6F5F5F7` |
| 来源与使用规范 | 局部署名 20／400 | 既有 TEXT `0xFFF5F5F7` |

该20字号仅用于非交互的来源署名，不扩展为按钮或常规说明字阶。三层沿用平台无衬线、统一 SP 换算与可读性处理；标题到作者日期间距12，作者日期到来源间距6，左侧80、底部56，宽度取屏宽减160与1100两者较小值，均为既有1920×1080设计坐标。每个角色最多两行、末尾省略，关闭额外字体 padding，空字段隐藏。

署名由 Scene 的 `captionTitle`、`captionDetail`、`captionSource` 承载，GalleryCollection 从目录生成相应结构化字段；界面不拆分组合好的 credit 字符串。有效旧缓存按 `artwork_id` 与目录身份匹配补齐这些字段，复用已缓存图片，无需为了更新署名重新下载。原有来源面板的组合署名继续保留。

摄影集的大标题显示用户命名，未指定时沿用文件名（去扩展名），系列署名只显示“摄影集”；作者日期角色为空时隐藏，沿用其余图库的字阶、间距和省略规则，不虚构人物、拍摄时间或CC0说明。

这是用户指定的局部署名调整，保留既有玻璃、应用布局、浏览遥控、HOME、签名及更新协议。新排版的截图交接目录为 `analysis/5.3.1-ui/`；前一版 `analysis/5.3-ui/` 的图片不能作为此排版的验收结论。
