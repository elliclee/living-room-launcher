# 素材说明

- `assets/wallpapers/coast.png`：原工程通过 OpenAI image_gen 生成的海岸背景；生成用途与提示词在相邻 `.json` 中。没有使用 Apple 截图或带品牌标志的图片作为壁纸。
- `res/drawable/ic_home.xml`、`tv_banner.xml` 及 TvAppearance.Glyph：项目内绘制的图形/入口资源。
- 第三方应用的图标/banner 在运行时从电视已安装的应用读取，仓库不捆绑这些品牌素材。
- 每日风景从 Bing 拉取，自定义背景由使用者配置；对外分发相关图片应另行核对相应权利，MIT 不授予第三方内容权利。

- `assets/art/`：芝加哥艺术博物馆公开 API 明确标为公共领域的作品，图像与基础元数据按 CC0；每件的原始作品名、作者、作品/API/IIIF 地址、摘要及核对日期见 catalog.json。中文展示名为项目内翻译。
- `assets/nasa/`：官方 NASA/JSC 航天摄影，按 NASA Images and Media Usage Guidelines 使用并署名，不标成 CC0。每件目录提供官方页面、API、核对日期及信用来源。
- 维护素材时运行 `python3 tools/fetch_art_collection.py`、`python3 tools/fetch_nasa_collection.py`，会访问官方服务并重验目录；日常构建仅打包已有文件，不联网抓图。
